## 一、定位与设计哲学

- Leemo = 像 Claude Code 一样能干的 AI 搭子——个人 AI OS 的起点。人格 momo（默默）。
- **冷工具 + 暖人格**：工具的部分（布局/结构线/信息密度）学 Linear 的克制精密；momo 的温度只从头像、文案、完成时刻微光效渗出。禁止廉价 AI 感（紫蓝渐变大色块/玻璃拟态滥用/圆角气泡堆砌）。
- **对话即操作**：一切高频动作 ≤1 步（拖入即引用、选中即问、/即技能、@即文件）。
- **文件即真相**：一切产物落盘 `~/Leemo/`，UI 只是文件的视图。一物三址：对话回执卡 + 成果架 + 磁盘。
- **名词预算 = 2**：用户可见名词只有「本子」「成果」。永不要求用户学习 Topic/Workspace/Agent/Session/RAG。
- momo 行为准则四条（06 §7.1）是所有界面文案的语气基准：会聊天有陪伴感 × 干活利落不啰嗦 × 需求模糊时选项确认 × 任务明确时安静做完。**"默默"≠沉默**。

## 二、双模式架构总纲（宪法 D 条落地）

### 2.1 一套数据层，两个渲染壳

```
BuddyShell（搭子）  ⇄  WorkbenchShell（工作台）      ← 二选一渲染，显式切换
────────────────────────────────────────────────
共享 Zustand stores（模式无关，唯一真相源）：
conversations / messages / runs / artifacts / notebooks /
approvals / notifications / settings / usage / wikiEntries / providers
────────────────────────────────────────────────
类型化 IPC 契约（preload）
```

- **铁律**：任何新功能先落共享 store，壳只做展示；**新组件不得直连 IPC**（lint 规则强制）；"搭子态不能做 X"类设计违宪（全能力轻展示）。
- 切换 = 换壳，对话/任务/记忆/产物原地不动；工作台跑着的任务切回搭子态照样收通知。
- 对话带 `source` 字段（'buddy'|'workbench'，08 §四），两边可见可续。

### 2.2 模式切换

- **顶栏固定两态切换器**：胶囊型分段控件 `[🫧 搭子 | ⚏ 工作台]`（图标+文字，当前态填充琥珀底），两壳同位（右上区）。
- 快捷键 **Ctrl+M** 随时切换（避开标签页 Ctrl+Tab）。
- 首次启动进搭子态；此后记住上次模式。
- 搭子聊出重任务 → momo 回复中内嵌"去工作台继续 →"轻链接（点击换壳定位到同一对话）——这是双模式教育的唯一机制，不做教程气泡。

## 三、Design Token 体系（K3 试镜定稿色板收编）

全部颜色/间距/圆角走 CSS 变量（`--leemo-*` 前缀统一收编 K3 稿的裸名 token）；浅色首发，深色二期只换 token 值。双基调 = 同一套语义变量在两壳下不同赋值：

| 语义 token | 搭子态（暖白，K3 buddy 稿） | 工作台态（冷灰，K3 workbench 稿） |
|---|---|---|
| `--leemo-bg` | #FAF6EE（暖米白） | #FFFFFF |
| `--leemo-bg-deep` / `--leemo-side` | #F2EBDC | #F6F6F7（侧栏）/hover #ECECEF |
| `--leemo-card` / `--leemo-panel` | #FFFEFB | #F8F8F9 |
| `--leemo-ink`（主文字） | #2D2822（暖黑） | #1C1C21（冷黑） |
| `--leemo-line` | #E9E0CE / soft #F0E8D8 | #E7E7EA |
| `--leemo-amber`（品牌琥珀） | #C07E1F（strong #A2660F / soft #F7E9CC / glow #EFCF9A） | #C07E1F（ink #8A6210 / bg #FDF9EE / line #EEDFC0） |
| `--leemo-ok` / `--leemo-danger` | —— / #DE524C | #4E9B6E / 同左 |
| 本子色板 | —— | `--leemo-book-blue` #6480A8 / green #6F9C7B / red #B0776E（本子图标着色循环） |
| momo 形象 | body #FFF8EA / line #E7D9BC / face #3B2F24 / blush #F2AC72 / spark #E9A23B / hi #FFFDF7（**两壳同值**——momo 是跨模式的同一个"人"） |

- 排版：UI system-ui；代码 JetBrains Mono/Cascadia；正文 15px/1.6；小字 12px；脚注 11px。
- 间距/圆角：卡片 padding 16 间距 12；卡片圆角 10（K3 稿实测手感）、按钮 8、输入框 14；阴影极轻 `0 1px 3px rgba(0,0,0,.05)`，hover 上浮+加深。
- 图标：线条图标（lucide 系），小尺寸克制；工具卡状态图标统一（🔄✓✗⋯ 的线条版）。
- viz UI Kit（08 §1.3）：`.viz-card/.viz-metric/.viz-button/.viz-tabs/.viz-table/.viz-range` 精简六件 + 图表色 token（`--leemo-viz-text/muted/grid/track/surface`），沙箱注入时映射宿主 token。

## 四、搭子模式规格（BuddyShell，K3 buddy 稿为准）

### 4.1 布局

- 无常驻侧栏。单列居中，内容列 max-width 720px，大留白。
- 顶部极简一行：左上 **历史按钮**（☰ 线条图标）；中/右上 模式切换器；右上铃铛（未读红点）。
- 画面中心偏上：**momo 头像**（内联 SVG，K3 稿定稿形象：暖白圆脸+眨眼+腮红，`momo-*` token 着色），呼吸动效（scale 1.0→1.02，3s 循环）+ 随机眨眼；说话时头像旁小声波微动。
- momo 开场白：按时段+记忆生成（如"早呀。昨晚帮你把《数据结构》第五章的笔记整理完了…"）；下方可挂**轻产物卡**。
- 输入框：大而友好（圆角 14），占位"跟 momo 说点什么…"；上方 2-3 个情绪化 chips（「帮我规划今天」「随便聊聊」「继续昨天的复习」，随上下文轮换）。

### 4.2 历史抽屉

- 点击 ☰ → 左侧抽屉滑出（320px，250ms ease-out，遮罩淡入）：搜索框 + 对话列表（含本子分组折叠视图只读概览）+ 底部"⚙ 设置"入口。
- 点任意对话 → 抽屉收起，该对话在搭子态继续（全能力）。

### 4.3 搭子态的消息展示（轻量规则）

- 工具过程：**一行人话微提示**（"翻了翻你的高数课件…"，灰字小号，可点开看完整工具卡）；并行工具合并为一句。
- 产出：**轻产物卡**（图标+标题+一句话，K3 稿样式），点击 → 换壳到工作台打开预览。
- 审批条/问询卡：与工作台同组件的轻样式变体（圆角更大、无边框底色更暖）——能力不降级。
- 计划卡：折叠为一行进度（"3 步计划 · 进行中 2/3"），点开展开。
- 用量脚注：同工作台规则（§7.8），底色适配暖白。

## 五、工作台模式布局（WorkbenchShell，K3 workbench 稿为准）

- **两栏默认**：侧边栏（260px，`--leemo-side` 底）+ 对话区；预览区/文件区按需从右侧展开（用户主动，永不自动弹）。
- 四栏（侧+对话+预览+文件树）只在用户全开时出现；预览区最小 300px，可拖拽分栏。
- 顶栏：左=当前对话标题（可改名，`title_manually_updated` 保护）；中=**上下文圆环**（§7.9）；右=模式切换器+铃铛。
- 多对话标签页：对话区顶部横向标签（最多 5 个，超出提示关闭；非激活 lazy）；Ctrl+Tab 切换。

## 六、侧边栏（工作台态）

结构继承 v1.1 骨架，人格换 momo，样式按 K3 稿（树状缩进线+对话计数）：

```
[+ 新对话]                     ← 顶部主按钮（琥珀描边）
🫧 momo                        ← 主对话常驻顶部（头像小尺寸）
📌 本子（可折叠分组）
  ▸ 📘 数据结构 (2)            ← book-* token 着色，计数
  ▸ 📗 高等数学
  ▸ 📕 例：高等数学             ← 预置示例本（首启含示例文件，可删）
  + 新本子
💬 对话（放养，按时间）
────
🔍 搜索 · 🧩 技能 · 📦 成果 · ⚙️ 设置   ← 一级导航
```

- 对话生命周期：新对话=放养 → 可"收进本子"/momo 顺口提议（可拒绝）。
- 徽标：新回复 ●；待审批 ⚠（琥珀）；后台完成 ✓ 状态条 3s。
- Ctrl+B 折叠为 48px 窄条（只留图标）。

## 七、对话流与消息组件（两壳共用组件库，只换密度皮肤）

### 7.1 消息基础

用户消息右对齐浅底；momo 回复左对齐带头像（小），流式 Markdown（打字机光标）；代码块带复制；消息组=一次 run 的连续输出合并渲染（单头像+整体复制）。

### 7.2 工具调用卡片（SDK tool_use → UI）

统一灰阶一行式（v1.1 规范保留）：`[状态图标] 动作 + 对象 · 补充`。进行中🔄/完成✓（绿）/失败✗（红）/后台⋯。点击展开参数与返回。并行折叠为"N 个并行操作"。**工具名映射注意（Phase 0 实证）：子 agent 的 tool_use.name 是 `Agent`（init 列表叫 `Task`）——渲染映射两名都认**，显示为"派了个小助手"。

### 7.3 计划卡（TodoWrite → UI）

CC 原生任务清单渲染为进度卡：标题+N/M 进度条（琥珀）+逐条 ✓/⏳/○（K3 稿样式）。实时更新。

### 7.4 活动卡（子 agent Task/Agent → UI）

折叠容器："🤝 momo 派了个小助手：整理文件 · 进行中"；可展开看子 agent 的工具流（forwardSubagentText 开启时）；完成后收拢为一行结果。

### 7.5 结果卡片（产物回执）

`[图标] 标题 + 一句话摘要 + 来源标注`，按钮：[打开预览] [放进本子] [在文件夹显示]。**用户主动打开，不自动弹**。

### 7.6 审批条（canUseTool → UI，06 §2.9）

对话流内嵌（K3 稿"安全但不吓人"气质）：一句人话说明（"momo 想写入 数据结构/笔记/第五章-复习笔记.md"）+ 三键 **[允许一次] [本对话总是允许] [永久允许]** + [拒绝]。危险操作（rm/格式化类）不显示"永久允许"键且条底色转 danger-soft。永久白名单入设置页可查可撤。**写入路径显示完整相对路径**——Phase 0 实证模型会臆造 cwd 外路径，路径本身就是用户判断依据；cwd 外绝对路径写入时条上加"⚠ 工作区外"角标。

### 7.7 问询卡（ask-user MCP → UI，08 §二）

momo 需要澄清时的结构化选项卡：题干 + 2-4 选项按钮（可多选）+ "其它…"内联输入。选择即回投（阻塞的 Promise 收到答案继续）。搭子态同组件暖样式。这是行为准则③的机制载体。

### 7.8 用量脚注（06 §2.6）

每条 momo 消息尾部常驻**折叠脚注**：默认只渲染一个 12px 灰色小圆点区；hover 才现形 `↑1.2k ↓0.8k · ¥0.003 · 3.2s`（11px 灰字）。数据来自 result 事件落库。

### 7.9 上下文圆环（08 §五）

工作台顶栏小圆环（16px）实时显示当前对话 token 占用比例（当前/压缩阈值，实测阈值 ~21k 起跳的相对比例由 Bridge 提供）；hover 提示"上下文 12.3k / 约 21k，快满时 momo 会自动整理"；压缩发生时圆环闪一次琥珀并 toast"momo 整理了一下记忆"。搭子态不显示圆环（压缩静默，只 toast）。

### 7.10 可视化卡（create_visualization → UI，08 §一 A 档）

momo 生成的交互组件内嵌消息流：sandbox iframe（allow-scripts；**不含** allow-same-origin）渲染自包含 HTML，宿主注入 `--leemo-*` token + viz kit CSS + CSP（禁外链/fetch/WS）。卡片壳：标题栏（文件名+[在成果中打开]+[全屏 ⤢]）+ iframe（高度自适应 max 520px，超出内滚）。同时落盘 `<本子>/成果/可视化/`。全屏 = 预览区打开。

### 7.11 错误与恢复

八态规范继承（loading/empty/ready/partial/error/offline/permission_blocked/stale）；错误条人话化 + [重试] 按钮；SDKAssistantMessageError 分类映射人话（authentication_failed→"API Key 好像失效了，去设置看看？"等）。

## 八、输入区（工作台全量；搭子只留输入框+chips）

布局继承 v1.1：chips 行（场景化 3-4 个 + /技能入口）→ 附件卡行（拖入即卡片，多文件+截图粘贴）→ 输入框（@文件 //技能 提示，Enter 发送，运行时变 ■ 停止）→ **折叠状态条**：`🧠 deepseek-chat · 智能放行 ▾`——点开 = **按对话选模型**面板（已配 Provider 分组列模型，选择即写入 conversation.{providerId,modelId}，下轮生效提示）+ 权限模式切换。

## 九、预览区 + 弹窗小 wiki

- 预览区：用户主动唤起（结果卡/文件点击/可视化全屏），右侧 0→展开 300ms；标签页多文件；Markdown 渲染 + PDF.js（含 TextLayer 选区）；Ctrl+. 开合。
- **选区交互**：选中文本浮出菜单 [问一下] [翻译] [复制] [高亮]。
- **小 wiki 弹窗**（06 §2.4）：[问一下] → 380px 浮窗（选区旁定位）：引用条（原文摘录+文件锚点）+ momo 简短回答（独立轻量 query()）+ **[详细一点] 开关** + 输入框**支持多轮追问**（同一轻 session）。关闭即收；**不进主对话历史**；写入 wikiEntries（全局搜索可搜）。
- **wiki 历史分区**：搜索页/侧栏"小问答"入口 → 按文件分组的 wiki 问答列表，点击回跳原文位置（首发到文件级，段落锚点二期）。

## 十、文件浏览器 · 十一、Skills 页 · 十二、全局搜索 · 十三、成果

- **文件**：右侧第四栏（用户唤起）；`~/Leemo/` 树；拖拽引用入输入框；右键（重命名/删除/在文件夹显示/移入本子）；文件状态角标（新/已引用）。拖入归类按 06 §2.2（上下文直落/momo 提议确认/Inbox 兜底）。
- **Skills**：一级导航全页；预置 3 张卡（费曼导师/期末速通/通用一张）+ 用户自装列表；启停开关；[打开技能目录]；三渠道触发说明文案。
- **搜索**：Ctrl+K 悬浮窗（居中 640px）；范围 = 对话+文件名+wiki+成果标题（SQLite FTS5）；结果分组显示；wiki 结果带"小问答"标签。
- **成果**：一级导航全页；按本子分组网格卡；可视化产物有专属图标；点击 = 预览区打开。

## 十四、设置页（左导航右内容）

分区：**模型**（Provider 卡片列表：四预置+自定义；每 Provider 内模型列表可拉取/增删；全局默认模型；连通测试）／**momo**（人设卡 3-4 张预置+自建、话风滑杆 3 档、momo 的记忆入口=打开 memory 目录+条目预览）／**联网**（AnySearch 默认状态+可选 key 源）／**权限**（永久白名单查看/撤销、危险清单说明）／**用量**（按 Provider/按日汇总，双日志数据）／**扩展**（自定义 MCP：stdio/SSE 表单）／**通用**（启动模式记忆、快捷键表、数据目录、关于）。

## 十五、首设向导（06 §3.5）

独立三步窗（非内联，因首启无对话上下文）：①选 Provider（DeepSeek 默认推荐卡+其余三家+自定义折叠）→ ②贴 Key（图文引导链接）→ ③一键测连通（真实小请求，错误人话化）→ 完成动效 → 进搭子态，momo 首句欢迎+示例本提示。目标 <2 分钟。跳过按钮允许"先逛逛"（无 key 态所有发送入口引导回向导）。

## 十六、通知（08 §五）

两级：应用内 toast（右下 3s，可点跳转）+ 系统通知（Electron Notification，仅后台任务完成/待审批且窗口非前台时）。铃铛面板=通知历史列表。

## 十七、快捷键

继承 v1.1 全表 + 新增：**Ctrl+M 模式切换**；Ctrl+Tab 标签切换；其余不变（Ctrl+K 搜索/Ctrl+N 新对话/Ctrl+B 侧栏/Ctrl+. 预览/Ctrl+L 聚焦输入/Esc 逐层关闭/@ / 触发）。

## 十八、动画

原则继承（有意义/200-400ms/ease-out/不滥弹簧 + `prefers-reduced-motion` 全局尊重）。关键动画表继承 v1.1 + 新增：模式切换=交叉淡入 300ms（壳换数据不动，禁白屏）；抽屉 250ms；可视化卡 iframe 加载=骨架闪烁；圆环压缩闪烁 600ms。momo 呼吸 3s/眨眼随机 4-7s。

## 十九、页面状态

八态齐全禁空白屏（v1.1 表继承）；新增：可视化卡 error 态（渲染失败显示"组件没画好，[让 momo 重画]"）；无 key 态（全局引导回向导）。

## 二十、UX 验收标准（用户目验清单）

1. 新用户装完 <2 分钟进入可聊状态；第一步聊或拖，无需解释
2. 首启搭子态第一印象 = 认识 momo（K3 稿气质）；切工作台 = 掌控感（Linear 气质）

5. 工具过程搭子态一行人话/工作台完整卡，同一数据
6. 审批条读得懂路径、危险操作无永久键、工作区外有角标
7. 问询卡点一下就能答；可视化卡能拖能点且不破界面
8. 产物永远找得回（回执卡/成果架/磁盘三址一致）
9. 预览区/文件树永不自动弹出
10. 用量 hover 可见、不打扰；圆环告知上下文状态
11. 全程零违禁名词；momo 语气符合四条准则
