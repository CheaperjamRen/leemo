# Leemo“开始”静态工作区视觉参数 v2

> 状态：用户已确认的最终视觉权威。
> 权威图：`start-static-workspace-v2.png`
> 生成原图：1586×992，比例约 16:10；生产验收视口为 1440×900，按同一比例实现，不裁切内容。

## 1. 视觉方向

- 锚点：成熟瑞士信息设计；
- 品牌识别：Leemo 橙色焦点轨迹；
- 记忆点：01–04 分区编号、1px 网格线、活动对象左侧橙色轨迹；
- 目标：信息丰富但不拥挤，安静但不空洞，所有内容都可直接操作；
- 禁止：暖黄纸张背景、渐变、玻璃拟态、卡通插画、巨型无意义图标、游戏式按钮、常驻 AI 输入框。

## 3. 网格

- 顶栏横跨整窗；
- 左侧导航固定，不跟随右侧内容滚动；
- 右侧采用 12 列网格；
- 01“待完成事项”和 02“今天”各占 6 列；
- 03“收集箱”和 04“最近”各占 6 列；
- 四张卡在 1440×900 内完整可见，不依赖页面纵向滚动；
- 卡内内容超出时限制预览条数，不能新增独立长滚动区。

橙色只用于当前表面、当前导航、卡片编号和真正主动作。同一屏不增加第二种高饱和强调色。

## 5. 字体层级

- 字体：系统中文无衬线优先，沿用 Leemo 全局字体栈；
- 品牌字标：24px semibold；
- 页面标题：28px semibold，tracking 约 -0.02em；
- 卡片标题：17–18px semibold；
- 列表标题：14px regular/medium；
- 路径、来源、计数和更新时间：12–13px；
- 不使用全大写装饰文案、伪代码式标签或无信息副标题。

## 6. 首页四类内容

1. **待完成事项**：最近一次成功的全局模型梳理快照；首页最多三项，明确更新时间、来源和手动刷新入口；
2. **今天**：用户明确安排到今天的 Todo；
3. **收集箱**：尚未整理的静默便签；
4. **最近**：最近打开的文档或文件。

“待完成事项”不是第二份 Todo。它可以把 Todo、会话、Run、成果和项目摘要归并为工作线预览；“今天”只忠实显示用户的日程承诺。

## 7. 待完成事项卡片

- 标题行包含“待完成事项”、最近成功更新时间和一个轻量刷新图标；
- 每行使用序号、事项标题和一行来源摘要；
- 最多三行，不在首页显示大段进展正文；
- 主动作“重新梳理”明确触发一次模型调用；
- 次动作“查看完整看板”进入全局看板；
- “由 momo 梳理”只作为低对比度来源说明，不做宣传文案；
- 尚无快照时不伪造条目，只显示说明和“为我梳理待完成事项”；
- 更新中保留旧快照；失败时保留旧快照并显示折叠错误。

## 8. 表面切换与 AI 边界

- 第一次启动默认进入“开始”；后续恢复上次表面；
- 选中“开始”使用浅橙表面、橙色图标与文字；
- 打开、停留、浏览、搜索、编辑和 Todo 操作不调用模型；
- 只有“为我梳理待完成事项”“重新梳理”或用户已明确启用的每日自动梳理可以更新该快照；
- 其他对象入口仍遵循：`问 momo`进入搭子，`进入工作台`进入工作台；挂载上下文本身不调用模型。

## 9. 响应式降级

- `1200–1439px`：左侧导航缩至 248px，卡片内边距降至 16px；
- `<1100px`：四卡改为单列，主页面允许纵向滚动；
- `<1024px`：左侧导航改为覆盖层；
- `<820px`：表面切换隐藏次级文字；
- 待完成事项在窄窗仍最多三项，来源摘要省略而不是让按钮换行；
- 所有弹层向可用空间展开，不推动页面主体。

## 10. 状态与动效

- Hover：120ms，背景或边框轻微变化；
- Focus-visible：2px 橙色半透明 ring，外偏移 2px；
- 页面切换：内容淡入与 4px 位移，160ms；
- 重新梳理时只旋转刷新图标或显示紧凑进度，不让整卡闪烁；
- `prefers-reduced-motion` 下关闭旋转和位移，仅保留状态文字。

## 11. 实现验收

- 1440×900 与 `start-static-workspace-v2.png` 逐区比较；
- 960×680 验证导航覆盖层、四卡单列和焦点返回；
- 无 Provider / API Key 时其余静态工作区完整可用；
- 未点击梳理且未启用自动化时，首页模型调用数为 0；
- 待完成事项全部可跳转到真实来源；
- 不出现伪造对象、伪造截止日期、模型自动完成 Todo 或静默刷新；
- 不出现横向滚动、裁切文字、按钮换行、弹层推动主体或过大无信息图标。
