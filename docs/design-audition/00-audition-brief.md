## 你的任务

为桌面 AI 产品 **Leemo** 制作两张高保真静态首屏页面（纯前端，假数据）：

1. `buddy-mode.html` —— 搭子模式首屏
2. `workbench-mode.html` —— 工作台模式首屏

**交付要求（硬性）：**
- 每张 = 一个完全自包含的单 HTML 文件：Tailwind 用 CDN（`<script src="https://cdn.tailwindcss.com"></script>`），其余 CSS/JS 全部内联；除 Tailwind CDN 与系统字体外零外部资源（图标用内联 SVG，头像用内联 SVG/CSS 绘制，**不得**引用外链图片/字体/图标库）。
- 视口按 1440×900 桌面窗口设计；浅色主题 only。
- 所有颜色定义为 `:root` 里的 CSS 变量（design token），Tailwind 任意值语法引用（如 `bg-[var(--bg)]`）。
- 界面文案全部中文，符合下方产品语境；假数据要像真的（课程名/文件名/对话内容写实，不要 Lorem ipsum）。
- 允许少量 CSS 动画（呼吸、淡入）；不写任何真实业务 JS 逻辑。

## 产品语境（认真读，这决定你像不像"懂这个产品"）

**Leemo** 是基于 Claude Code 引擎的个人 AI 工作台+搭子，面向中国泛年轻人（大学生为首发人群）。内置 AI 人格叫 **momo（默默）**——懂你的学长/学姐气质：会聊天有陪伴感、干活干净利落不啰嗦。名字含义是"事情默默就位"，**不是**沉默寡言。

产品有两个显式切换的模式，**一套数据、两个壳**：

- **搭子模式**：像和朋友聊天。单栏居中（内容列 max-width ≈720px）、大量留白、暖白基调、琥珀色点缀。momo 的存在感强。
- **工作台模式**：像 Linear 那样克制精密的生产力工具。侧边栏+对话两栏、冷灰基调、信息密度高。momo 的温度只从头像、文案、微动效里渗出。

**视觉总纲：冷工具 + 暖人格。** 工具的部分（布局、卡片、结构线）越冷静越好；人格的温度只允许通过 momo 头像、语气文案、完成时刻的微光效透出来。禁止廉价 AI 感（不要紫蓝渐变大色块、不要玻璃拟态滥用、不要圆角气泡堆砌）。

**名词纪律**：用户可见名词只有「本子」（=一门课/一个项目的文件夹）和「成果」（=AI 产出的东西）。不得出现 Topic/Workspace/Agent/Session 等词，不得出现"幸运鹿/Lulu"。

## 页面 1：搭子模式首屏（buddy-mode.html）

老用户（用了三周的大二学生）早上打开 Leemo 看到的样子：

- 顶部极简：左上角历史抽屉按钮（图标）；顶部中央或右上一个「搭子 ⇄ 工作台」两态切换器；右上铃铛（有 1 条未读小红点）。无常驻侧边栏。
- 画面中心偏上：momo 头像（内联 SVG 画一个简洁、有辨识度、亲和的形象——自行设计，这是加分重点），带极缓慢的呼吸动效。
- momo 的开场白（示例语气，可微调）："早呀。昨晚帮你把《数据结构》第五章的笔记整理完了，放进本子里了。今天想从哪儿开始？"——下方一张**轻产物卡**（小卡片：📄 第五章·树与二叉树 · 复习笔记 · 点击去工作台查看），这是"搭子态产出轻展示、点击跳工作台"的关键交互。
- 输入框：大而友好，圆角，占位文案"跟 momo 说点什么…"；输入框上方 2-3 个情绪化 chips（如「帮我规划今天」「随便聊聊」「继续昨天的复习」）。
- 整体氛围：早晨、安静、被照顾着的感觉。暖白底（不是纯白），琥珀点缀克制。

## 页面 2：工作台模式首屏（workbench-mode.html）

同一个用户切到工作台，正在让 momo 干活的样子：

- 左侧边栏（~260px，冷灰）：顶部 Leemo 标识；「+ 新对话」；本子分组列表（📘 数据结构、📗 高等数学、📕 毛概，其中数据结构展开显示 2 个对话）；下方「放养对话」组 1-2 条；底部设置/momo 头像小入口。
- 主区对话流（发生中的任务，按序展示）：
  1. 用户消息："把第五章 PPT 里的重点整理成复习笔记，存到本子里"
  2. momo 简短回应一句
  3. **计划卡**（TodoWrite 渲染）：3-4 步清单，前两步 ✓ 完成、第三步 ⏳ 进行中
  4. **工具卡片** 2-3 张（统一灰阶、一行式、可展开样式）：「读取 第五章-树与二叉树.pptx」「搜索 本子内相关笔记」等，状态图标 ✓/🔄
  5. **审批条**（内嵌对话流）：momo 想写入文件 `数据结构/笔记/第五章-复习笔记.md`，三个按钮：允许一次 / 本对话总是允许 / 拒绝——这是重点组件，做出"安全但不吓人"的气质
  6. 一条 momo 的流式回复气泡（正在生成的状态）
- 每条 momo 消息下有**折叠的用量脚注**（极低调灰字，hover 才现形：`↑1.2k ↓0.8k tokens · ¥0.003`）。
- 输入框：底部，带 @引用、/技能、附件三个小图标。
- 右上：同款模式切换器（当前在工作台侧）。
- 整体氛围：Linear 式的克制精密，冷灰层次分明，momo 的暖只在头像和完成时刻。
