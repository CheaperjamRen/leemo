## 执行纪律

- 一张卡一个明确用户结果；默认 90 分钟内形成可运行增量，超时先缩回原需求边界。
- Review Budget = 1：一次独立评审、一次修复；第二轮发现记账，只有 P0 阻塞推进。
- 聚焦测试随卡运行；全量测试、NSIS、截图和性能数据在里程碑统一执行。
- 并行 agent 必须使用独立 worktree 或互不重叠的文件所有权，并拿到明确验收命令。
- 新想法进入本文件相应队列；除非直接阻塞当前用户路径，否则不插队 P0。
