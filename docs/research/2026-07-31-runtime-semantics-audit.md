# R11 设置语义与运行时一致性审计

日期：2026-07-31
范围：联网搜索/抓取、记忆、浏览器、权限策略、模型能力探针、定时任务。

## 审计原则

用户看到的一个开关，必须同时决定五件事：

1. momo 的能力说明（提示词）；
2. 下一轮实际暴露给模型的工具；
3. 旧 SDK 回调漏进来时的权限结果；
4. 设置改变后当前对话的热生效；
5. 重启/失败时的可理解结果。

本审计不把第三方 MCP 的自报标签当作可信来源。能力归属只能由 Leemo 自己维护的注册表签发；未知第三方工具继续走审批，避免“带了 search 字样就自动放行”的越权。

## 结果矩阵

| 用户心智 | 生效状态来源 | 提示词 | 工具暴露 | 权限代理 | 结论 |
|---|---|---|---|---|---|
| 联网搜索 | `webEnabled && webSearchEnabled` 的生效值 | 明确说明能否搜索 | 原生 `WebSearch`、Leemo 通用搜索、arXiv 作为同一联网搜索组接线 | 同一对话状态实时拒绝/放行；关闭时不受 `bypassPermissions` 复活 | 已修复并由宿主热切换测试钉住 |
| 联网抓取 | `webEnabled && webFetchEnabled` | 明确说明能否抓取已知网址 | `WebFetch` 结构性加入/移出禁用表 | 同一状态拒绝/放行 | 已对齐 |
| 记忆 | `rememberMode` | 全局/本子记忆是否可读写 | memory MCP、原生 Auto Memory 和当前视图同步切换 | 记忆工具与提示词使用同一可变状态 | 已修复并由宿主热切换测试钉住 |
| 浏览器 | Leemo 受控 Playwright MCP 是否实际可用 | 当前只在工具层呈现，不把内部实现暴露为产品心智 | MCP 配置刷新时增删 | 仅精确放行 Playwright 只读动作；浏览器关闭或未知 MCP 仍拒绝/询问 | 已对齐；写入/点击等动作仍不免询问 |
| 权限模式 | 单个可变 `PermissionPolicy` | 不改变 momo 能力描述 | SDK 仅保留 plan 的原生只读约束，其余由 broker 执行 | `default / acceptEdits / bypassPermissions` 实时读取同一 policy | 已对齐 |
| 模型视觉/思考 | 连接测试的证据 + 用户选择 | 仅作为能力提示，不替用户拒绝附件 | 附件仍按用户选择发送 | 不因探针失败自动拒绝图片 | 已按“证据而非裁决”保留 |
| 定时任务 | 任务记录 + 当前工作区/权限/模型快照 | 运行记录如实说明成功、失败、漏跑 | 复用现有对话工具链 | 继承任务创建时的权限边界 | 已按本地恢复路径验收 |

## 本轮修复

- 新增可信的内置能力注册表：搜索、抓取、记忆和浏览器只读动作各自绑定到明确的用户能力开关；未知第三方 MCP 不受影响。
- `personaCtx` 现在是每个对话唯一的可变能力状态，同时交给提示词、工具接线和 `createApprovalBroker`。设置广播只修改它，不再出现“屏幕已打开、工具结构已打开、broker 仍关闭”的三层分叉。
- 原生 WebSearch、Leemo 通用搜索 MCP 与 arXiv 接线集中在一个宿主函数。新增搜索适配器只需加入这个能力组，不需要在创建、换模型、热更新三条路径各自补一遍权限白名单。
- 配置 MCP 刷新时同步更新浏览器能力状态；浏览器只读动作的信任范围仍是精确动作表，不按名称模糊匹配。
- 保留永久 `[leemo:ctx]` 轻量日志，记录当前对话的开关到达情况，不记录密钥、提示词正文或文件内容。

## 有意保留的边界

- “联网搜索”不是“所有联网工具全部免询问”：网页搜索/arXiv 是只读能力；第三方 MCP、写入、点击、上传、Shell 等仍按风险审批。
- 新增一个真正独立的内置联网工具时，必须显式加入能力注册表和搜索能力组；不能靠名称约定自动放行。这样是一次性的工程接线成本，换来不会把恶意/未知 MCP 误当成可信工具。
- 秘塔、Google 等供应商是通用搜索链的适配器，不各自新增权限工具；因此以后增加供应商不会重复制造用户权限卡。

## 验收证据

- `tests/bridge/interact.test.ts`：关闭状态覆盖 WebSearch、WebFetch、通用搜索、arXiv、记忆和浏览器只读工具；无审批卡。
- `tests/host/bridge-host.test.ts`：搜索和记忆在同一对话中关闭→开启后，下一次 broker 调用立即从拒绝变为放行；提示词和结构接线同时更新。
- 后续必须在打包应用重跑搜索用户路径；源码绿不等于 Electron/原生 SDK 回调已经接上。
