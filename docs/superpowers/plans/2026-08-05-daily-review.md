# 每日回顾：自动汇总纵向切片

## 目标

从搭子态进入「回顾今天」后，Leemo 用现有对话、产物、定时任务和未完成状态生成一段事实优先的回顾。回顾是普通的 momo 对话，可继续追问、搜索和写文件；不创建新的报告数据库，也不自动写入长期记忆。

## 范围

1. 新增纯函数，把当天数据压缩为有上限的事实摘要和稳定 prompt；空数据时明确写空，不编造。
2. 在搭子态提供常驻的「回顾今天」入口；首次点击创建并保存一段全局对话，重复点击复用当天回顾对话。
3. 用现有时间线和 persistence 验证发送、错误、重启恢复；不改心迹、记忆协议、工作台全局布局。

## 验收

- 有今日记录时，prompt 包含对话、产物、任务状态且每类有长度上限。
- 无今日记录时，模型收到明确的“暂无记录”，不能被 UI 诱导编造。
- 点击只创建一段当天回顾对话；重开应用后仍能从历史继续。
- 失败显示现有重试状态；日后继续对话不要求回答额外问题。
