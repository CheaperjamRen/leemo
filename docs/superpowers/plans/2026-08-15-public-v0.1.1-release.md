# Leemo v0.1.1 Public Debug Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a clean, reproducible Leemo v0.1.1 source snapshot and unsigned Windows installer for public portfolio debugging.

**Architecture:** Commit all first-party project source, tests, product documents, and approved design assets as a local source snapshot, then write that exact tree as one clean release commit on top of the current public `origin/main`. This avoids publishing hundreds of private development-history commits while preserving every approved project file. Keep generated packages out of Git history and attach the installer to a GitHub prerelease. The local Anthropic Office Skill payload remains excluded because its bundled license explicitly prohibits redistribution; Leemo's Office integration and verification code remain public.

**Tech Stack:** Git, GitHub Releases, Node.js/npm, Electron Builder, PowerShell.

## Global Constraints

- Version is exactly `0.1.1`; Git tag is exactly `v0.1.1`.
- README decoration is out of scope for this release step.
- Never commit `.env`, credentials, personal runtime paths, caches, generated QA screenshots, unpacked applications, or package output.
- Include all licensable Leemo source, tests, product documents, visual design assets, and Office integration code.
- Do not publish the local `bundled-skills/office/release/skills` payload; its own license forbids copying and distribution.
- Put temporary files and package caches on drive E.
- The installer is a GitHub Release asset, not a tracked Git file.
