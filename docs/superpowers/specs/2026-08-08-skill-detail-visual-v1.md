# Leemo 技能详情页视觉规范 v1

## 用户目标

用户进入详情页后，应在一个视口内理解：这个技能能做什么、如何让 momo 使用、是否需要安装，以及它来自哪里。

## 已批准结构

- 顶部为紧凑身份区：中文名、原始名、来源标签、单句用途和安装操作；禁止大幅宣传封面。
- 主区左侧优先呈现“它能帮你做什么”“你可以这样对 momo 说”“使用方式”。
- 示例话术可直接复制或带入对话，帮助非技术用户立即上手。
- 右侧集中呈现安装状态、版本、权限范围、来源与许可证；技术元数据保持次级层级。
- 所有操作按钮保持单行，不用开发者 README 式长篇说明。
- 安全状态只能陈述真实检查结果；使用“已通过基础检查”和可查看的检查详情，不使用“安全、稳定、合规”等泛化承诺。
