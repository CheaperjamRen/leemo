# Leemo 看板「待办」视觉规范 v1.0

> 日期：2026-08-08<br>
> 状态：产品视觉方向已批准；页面中已出现的能力是实施下限<br>
> 视觉基准：`docs/design-audition/visual-redesign/workboard-tasks-v1.png`

## 页面目标

把“快速记下一句话”和“第一次就把一条待办设置完整”放进同一个克制界面。用户既能马上记录，也能在需要时补齐计划、截止、提醒、重复与本子，不被迫来回跳页。

## 创建体验

- 顶部保留一个会随内容自然增高的输入区，支持一句话或多行批量输入；
- 本地识别出的日期、提醒和本子以可编辑标签展示；多日期角色不明确时显示「需要确认」，不猜；
- 「补充信息」默认收起，展开后一次填写完整字段；
- 快捷输入可以直接选择「今天」或「不限期限」，不选择时维持默认未标记；
- 创建动作清晰，但不使用大面积高饱和 CTA 抢夺列表注意力。

## 日期与状态语义

- 默认未标记的待办在创建当天先显示于「今天」，跨日未完成后自动进入「不限期限」，不计入未完成；
- 只有用户明确标记「今天」的待办，跨日后才进入「未完成」；
- 明确标记「不限期限」的待办从创建起就在不限期限分组；
- 列表至少支持「未完成 / 今天 / 即将到期 / 已完成」筛选，并按「今天 / 接下来 / 不限期限」形成稳定分组。

## 列表与操作

- 每条待办优先显示标题，日期、提醒、本子和来源作为次级信息；
- 圆形完成控件、完成后重开、编辑、移入回收站都保持既有能力；
- 到期风险用少量暖色提示，不把整张卡染红；
- 当前阶段不加入 Kanban、连续打卡或复杂统计，不把行动清单变成项目管理系统。

## 视觉约束

- 继承已批准工作台壳层、冷中性石灰底、暖白内容面、深墨蓝正文与少量琥珀强调；
- 右侧「文件 / 概览 / 搜索」工具栏在未打开时全部保持中性，效果图中的高亮不作为实现要求；
- 信息密度高于普通聊天页，但通过分组、字重和留白建立层级，避免一排等权卡片；
- momo 不在待办页主动发言，也不以大头像占据工作空间。
