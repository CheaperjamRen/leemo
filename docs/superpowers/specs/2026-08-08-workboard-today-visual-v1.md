# Leemo 看板「今天」视觉规范 v1.0

> 日期：2026-08-08<br>
> 状态：产品视觉方向已批准；等待前端统一实施<br>
> 视觉基准：`docs/design-audition/visual-redesign/workboard-today-v1.png`

## 页面目标

「今天」不是 AI 自动写出的日报，也不是等权数据卡片集合。它优先回答：用户今天要做什么、Leemo 正在做什么、哪里正在等用户处理，以及最近捕获了什么。

## 信息顺序

1. 今天要做；
2. 正在执行；
3. 等你处理；
4. 收集箱；
5. 最近成果；
6. 继续记录。

宽屏采用主次双栏：行动与 Agent 状态位于左侧主栏，记录和成果位于右侧次栏。每个区域内部使用行、分隔线和少量状态标签，不把每项内容单独做成浮卡。

## 交互与视觉

- 顶部固定「今天 / 便签 / 待办 / 回收站」；
- 全局范围默认是「全部」，筛选不移动数据；
- 左下「看板」是全局工作看板入口；右侧「概览」只表示当前工作范围概览，二者不能产生重复激活语义；
- 看板打开时右侧「文件 / 概览 / 搜索」均保持中性，只有用户明确打开对应工具时才激活；
- 运行状态使用细进度线和一个小型活动标记，不使用大号 momo 或 AI 回复；
- 页面不显示虚构生产力分数、连续打卡、泛化图表或主动生成的励志话语；
- 窄窗口回到单列，保持「今天要做」和「等你处理」优先。
