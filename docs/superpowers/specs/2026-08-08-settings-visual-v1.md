# Leemo 设置视觉规范 v1

## 总体框架

- 设置使用居中的大型中等弹窗，不使用窄侧栏页，也不强制切换全屏。
- 左侧为固定搜索与分类导航，右侧为当前设置页。
- 分类使用用户语言：通用、模型、用量与费用、个性化、连接器、权限、数据与存储、快捷键、关于。
- 不显示编号前缀、Claude Code 名称、内部别名、环境变量或协议实现术语。

## 内容排版

- 设置正文默认使用 Codex 式单列分组，不使用紧凑的多列卡片矩阵。
- 每项独占一行：名称和简短说明在左，开关、选择器或分段控件统一右对齐。
- 分组通过标题、留白与细分隔线建立秩序，保持成年向桌面软件的从容感。
- 即时开关自动保存；仅涉及凭据或复杂配置的页面使用明确保存动作。

## 通用页

- “关闭窗口后继续运行”默认开启；“开机时自动启动 Leemo”默认关闭。
- 提供启动后进入页面、系统通知、通知范围、主题、界面密度、文字大小、语言和时区。
- 底部以轻量文字说明更改会自动保存。

## 模型页

- 设置导航中将“用量与费用”作为独立分类，模型页只处理接入、模型清单和测试。
- 模型页内部使用两栏：左侧为已启用模型及默认优先级，右侧为当前模型的连接与模型配置。
- 已启用模型可直接拖动排序，首项为默认；不要求用户跨高级设置和连接页面往返。
- 当前连接区在同一页提供 API Key、服务地址、接口格式、可用模型、主备顺序与测试连接。
- 测试连接以最低合理成本检测连通性、图片输入和深度思考；检测未知或失败只作提示，不禁止用户使用。
- 高级设置不得出现 Claude Code 角色、模型别名或内部环境变量心智。
- 复杂配置使用明确的“保存设置”；主操作使用深墨蓝，琥珀色只承担选中和状态强调。

## 添加模型

- 从可搜索的预设目录选择服务，再进入带预填信息的连接页；禁止让普通用户从空白技术表单开始。
- 预设按常用、API 服务、订阅与计划、聚合服务分区，并提供完整搜索。
- 卡片使用中文可读名称、短用途和小型类别标签，整张卡可点击，不在卡内再放按钮。
- 订阅与 Coding Plan 说明复用本机已安装且已登录的官方客户端；Leemo 不随包捆绑对应 CLI。
- 自定义模型服务保持清晰入口，可配置服务地址、密钥和接口格式。
- 选择页不出现“移除、取消、保存设置”等不属于该步骤的操作。

## 用量与费用

- API 与订阅模型都记录调用次数、输入词元、输出词元、缓存读取、缓存创建和缓存命中率。
- API 金额标为“预计支出”；订阅模型不伪装成实际扣费，标为“订阅内”，并按公开模型费率展示“等价价值”。
- 页面顶部同时汇总 API 预计支出、订阅等价用量、调用次数、输入/输出词元和缓存命中率；筛选日期、来源或模型时，图表和明细同步变化。
- 趋势图可在支出、等价价值和词元之间切换；模型排行不因订阅来源而隐藏真实用量。
- 模型明细在同一行保留类型、调用次数、输入、输出、缓存以及“费用 / 等价价值”，订阅行使用“订阅内 + 等价金额”的双层表达。
- 费率采用可维护的本地模型表：复用 CC Switch 的 MIT 许可数据结构、模型 ID 归一化和种子费率，允许用户覆盖；在线更新不得成为离线启动前提。
- 费率变化只影响后续估算；每条历史用量应保留当时的计价依据，避免刷新费率后静默改写旧统计。
- 页脚提供克制的“管理模型费率”和“管理数据”入口，并明确估算值可能与服务商账单存在差异。

## 个性化

- 页面围绕“相处风味、关系定位、让 momo 认识你、称呼与补充偏好”组织，不做内部参数面板或人格测评表。
- 相处风味提供自然、ENTP、INFJ、ENFP、ENTJ；MBTI 只描述表达气质和思考倾向，不给用户贴标签，也不机械扮演刻板人格。
- 关系定位提供朋友、搭档、学长/学姐、导师，只改变相处距离、称呼和建议姿态，不改变任务能力。
- “和 momo 认识一下”保持常驻明显入口，允许开始关系对话，也能随时查看、编辑或纠正 momo 对用户的理解。
- system prompt 使用稳定能力底座叠加短小风味层：用户任务、事实准确性、工具使用、完成度、安全与权限边界始终由共同底座保证；风味层只能影响语气、关注角度、追问方式和建议组织方式。
- 任何人格都不得曲解、拒绝普通任务，或因追求角色差异而省略应回答的信息、降低推理质量和执行能力。
- 后续用少量代表性任务做风味对照：用户应能辨认差异，但同一任务的正确性、完整度和可执行性不得明显下降。

## 连接器

- 页面按“联网搜索、学术论文、浏览器操作、操作电脑、其他连接器”等用户能力组织，不以 MCP、协议或插件实现方式组织。
- 联网搜索使用总开关加原位折叠列表；默认显示“12 个来源 · N 个已配置”，点击整行后直接展开各搜索服务的启用与配置状态。
- 通用搜索来源覆盖 AnySearch、豆包、秘塔、Tavily、博查、Google CSE、Exa、Brave Search、SerpAPI、Serper、Bing Search、Firecrawl；arXiv 继续归入独立的“学术论文”。
- 不提供“管理来源”的二级跳转；后续新增搜索来源时，只扩展同一折叠列表。
- 浏览器操作默认只显示当前浏览器与连接状态；原位展开后选择 Leemo 浏览器或当前 Chrome，并提供检查连接。
- 操作电脑独立成组，删除“了解范围”跳转；原位展开读取屏幕、鼠标键盘和登录接管等范围说明。
- 同页信息优先使用“摘要 + 原位折叠”；只有添加自定义连接器这类完整复杂表单才进入独立配置界面。
