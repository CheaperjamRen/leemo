# Leemo 定时任务视觉规范 v1

## 产品心智

定时任务是重复执行规则的管理列表，不是日历或个人日程规划产品。

## 已批准主视图

- 主页面只展示任务列表，不使用七日历、月历、侧栏时间线或统计看板。
- 每行回答：做什么、重复频次、下次执行、上次结果、所属本子或全局范围、是否启用。
- 重复规则需要支持每日、每周指定星期（可多选）、每月、每工作日和每周末。
- 失败使用小型状态点和“查看原因”，不出现大面积告警卡。
- 关闭窗口后后台运行仅在底部轻量提示，并提供设置入口。
- 用户创建的任务类别不可预知，因此禁止自动分配带类别暗示的个性化图标；列表使用统一中性标记或纯文字层级。

## 视觉规则

- 使用全宽紧凑列表与细分隔线，一屏约展示六条任务。
- 频次、状态、按钮和星期标签保持单行，暂停项目降低对比度但仍可读。
- 沿用 Leemo 暖象牙白、燕麦灰、深墨蓝与少量琥珀色的整体系统。

## 新建与编辑弹窗

- 使用一个中型弹窗一次完成任务名称、自然语言要求、执行范围、重复频次、执行时间与通知方式。
- 重复频次直接使用“每天、每周、每月、工作日、周末”等用户语言，禁止暴露 Cron、RRULE 等实现术语。
- 仅在选择“每周”时展开星期一至星期日的多选；其他频次不显示无关字段。
- 全局 momo 与具体本子为同一“在哪执行”选择，不要求用户跨页面配置。
- 低频选项收进“更多设置”，默认表单保持一屏可完成。
- 弹窗底部轻量说明关闭窗口后仍会后台执行。
