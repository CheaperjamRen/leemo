# Leemo 看板「便签」视觉规范 v1.0

> 日期：2026-08-08<br>
> 状态：产品视觉方向已批准；页面中已出现的能力是实施下限<br>
> 视觉基准：`docs/design-audition/visual-redesign/workboard-notes-v1.png`

## 页面目标

便签是比聊天可靠、比正式文件轻的安静思考空间。页面采用「全局地图 / 便签列表 / 沉浸编辑」三级结构；用户编辑时不显示 AI 回复流，也不自动改写或分类。

## 必须保留的可见能力

- 标题与正文搜索；
- 全部与已归档切换；
- 新建、归档、移入回收站；
- 自动保存状态；
- 标题、正文、标题层级、粗体、有序和无序列表、圆形清单、引用、撤销与重做；
- 粘贴图片、添加附件及更多格式入口；
- 本子关联；
- 自动识别网页链接，并在编辑状态下以 `Ctrl + 点击`调用默认浏览器；
- 附件的「打开文件 / 在资源管理器中显示」；
- 字数与保存状态；
- 用户明确触发的「交给 momo」入口。

这些元素是实现下限；可以加入确实有益且不打断写作的渐进功能，但不能用新增元素挤压正文或制造默认 AI 打扰。

## 文件与外链

- 网页链接使用全局外链组件；
- 外部引用与托管副本都提供「打开文件」和「在资源管理器中显示」；
- 托管副本可以显示「已保存副本」，外部文件显示「仅引用」；
- 文件失效后保留文件名、原路径和失效说明，便签正文继续可用；
- 已转为本子文档的便签额外显示对应 Markdown 文件的打开与定位入口。

## 视觉约束

- 便签列表使用紧凑文字行，不堆叠浮卡；
- 选中项使用淡墨蓝背景与细琥珀标记；
- 编辑器以排版和留白为主，工具栏紧凑、图标一致；
- momo 不以头像或常驻面板出现，仅在用户主动调用的按钮或临时操作条中轻量出现；
- 窄窗口优先保留编辑器，便签列表折叠为可唤起面板。
