# Leemo Skill Hub 视觉规范 v1

## 已批准方向

- 桌面端三列卡片，不使用四列拥挤布局。
- 通过压缩卡片上下高度提高信息密度；不压缩横向可读空间。
- 一屏应完整看到三排技能卡，搜索、来源分区和分类筛选仍保持清晰。
- 技能图标仅作快速识别，约 32–36 px；禁止无信息价值的大面积装饰图。
- 卡片名称优先显示用户可理解的中文名；知名品牌名可保留，原始英文名和 GitHub 来源作为次级信息。
- 每张卡最多两行用途简介，底部为单行分类与单行操作；按钮、套件数量和状态不得换行。
- 套件卡明确展示包含的技能数量，并提供单一“安装整套”操作。

## 视觉语言

- 沿用 Leemo 已批准的暖象牙白表面、燕麦灰背景、深墨蓝文字和少量琥珀色强调。
- 使用细边框、轻层次与紧凑的成年向排版，不使用大渐变、玻璃拟态或幼稚插画。
- 内容优先级依次为：名称与用途、来源可信度、状态与操作、分类。
