# Independent review matrix

Run before final packaging. A reviewer must be able to mark `PASS`, `FAIL`, `NOT_APPLICABLE`, or `NOT_VERIFIED` without relying on the drafting agent's memory.

| Gate | Status | Evidence / artifact | Blocking finding | Owner |
|---|---|---|---|---|
| Research question and scope are explicit | NOT_VERIFIED | | | |
| Search or data protocol is reproducible | NOT_VERIFIED | | | |
| Every included source is identifiable and access-compliant | NOT_VERIFIED | | | |
| Evidence rows point to retrievable source locations | NOT_VERIFIED | | | |
| Material claims map to evidence and contradictory evidence is represented | NOT_VERIFIED | | | |
| Planned work is not reported as executed | NOT_VERIFIED | | | |
| Statistics preserve confirmatory / sensitivity / exploratory distinctions | NOT_VERIFIED | | | |
| Figures trace to data, code, and statistical decisions | NOT_VERIFIED | | | |
| Quotations, paraphrases, and borrowed structures are attributed | NOT_VERIFIED | | | |
| Uncertainty, limitations, and negative results are preserved | NOT_VERIFIED | | | |
| Central answer is visible before process detail | NOT_VERIFIED | | | |
| Detail is proportionate to audience, stakes, and deliverable | NOT_VERIFIED | | | |
| All load-bearing coverage modules have an honest disposition | NOT_VERIFIED | | | |
| Contradictions and credible alternatives receive appropriate weight | NOT_VERIFIED | | | |
| Terminology, method standards, and claims fit the discipline | NOT_VERIFIED | | | |
| Confidence wording matches evidence directness, quality, agreement, and coverage | NOT_VERIFIED | | | |
| User can distinguish completed work, uncertainty, and the next action | NOT_VERIFIED | | | |
| Interaction is concise, non-scolding, and does not expose internal skill-learning burden | NOT_VERIFIED | | | |
| Privacy, external upload, human-subjects, and regulated-domain checks are resolved | NOT_VERIFIED | | | |
| Third-party licenses and redistribution boundaries are recorded | NOT_VERIFIED | | | |
| Final artifacts and unresolved risks are listed | NOT_VERIFIED | | | |
